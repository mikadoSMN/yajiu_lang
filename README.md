- *あくしろよ* - ポインタをインクリメント
- *やりますねぇ!* - ポインタの指す値をインクリメント
- *びっくりさせたる!* - ポインタをデクリメント
- *いなりが入ってないやん* - ポインタの指す値をデクリメント
- *すいません許してください!何でもしますから!* - ポインタの指す値が0なら 対応する 'ん?今何でもするって言ったよね?' の直後にジャンプ
- *ん?今何でもするって言ったよね?* - ポインタの指す値が0で無いなら 対応する 'すいません許してください!何でもしますから!' までジャンプする
- *見たけりゃ見せてやるよ* - ポインタの指す値を出力
- *ンアッー!* - 入力から1バイト読み込みポインタが指す先に代入


それ以外の文字や改行は全て無視されます
